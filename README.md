# Python — Machine Learning Learning Lab

This is an **educational notebook archive**, not a collection of deployed/validated models. It includes decision trees, neural networks, SVM, K-Means, hierarchical clustering and geometric demonstrations.

## Browse
- [Decision trees](Decision_tree.ipynb)
- [K-Means clustering](KMeans_Clustering.ipynb)
- [SVM](SVM.ipynb)
- [ANN](ANN_using_sklearn_(diabetic_dataset).ipynb)

Open notebooks in Jupyter or Colab. Some load local Colab paths (e.g. `/content/diabetes.csv`); obtain the licensed dataset and adjust paths. Dependencies vary and this whole archive has not been verified end-to-end. Many examples use toy datasets; results must not be treated as validated business or medical predictions.
